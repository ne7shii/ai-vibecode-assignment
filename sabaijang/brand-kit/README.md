# brand-kit · รูป CWN สบายจัง รีสอร์ท

ในเรื่องราวของบทเรียน นี่คือรูปที่คุณวิภาส่งให้ทีมทำเว็บ แต่รูปจริงทั้งหมด **มาจากคลังภาพฟรี** (StockSnap, Flickr, Wikimedia Commons) ไม่ใช่รูปของโรงแรมจริง และคนในภาพไม่ใช่ตัวละคร ที่มาและสัญญาอนุญาตของทุกรูปอยู่ใน [`CREDITS.md`](CREDITS.md) รูปที่เป็น CC BY / CC BY-SA ต้องแสดงเครดิตในเว็บ

| โฟลเดอร์ | มีอะไร |
|---|---|
| `rooms/` | ห้องละ 5 รูปตามรหัสห้อง `r01-*` ถึง `r06-*` (ห้องนอน ห้องน้ำ วิว และมุมอื่น) |
| `pano/` | ภาพ 360° แบบ equirectangular (2:1) สำหรับ R03 `pano-r03` · R05 `pano-r05` · R06 `pano-r06` |
| `resort/` | `hero-beach` `hero-pool` `hero-sunset` ภาพใหญ่ 3 ภาพ · ภายนอก ล็อบบี้ สระ ห้องอาหาร อาหารเช้า สปา ฟิตเนส Kids Club ที่จอดรถ มุมทำงาน · ฮันนีมูน (ดินเนอร์ ตกแต่งเตียง) เค้กวันเกิด · รถรับส่ง สนามบินภูเก็ต · จุดชมวิวกะรน เมืองเก่าภูเก็ต |
| `events/` | สงกรานต์ ลอยกระทง Countdown Gala Dinner |
| `people/` | `staff-gm-wipa` คุณวิภา · `staff-sales-golf` คุณกอล์ฟ · `staff-front-muk` น้องมุก · `staff-room-chai` พี่ชัย · `guest-*` ผู้เข้าพักที่ให้สัมภาษณ์ |
| `misc/` | `login-side` `empty-state` `promo-bg` `rain-green` (พื้นหลัง Green Season) |

ภาพจาก StockSnap กว้าง 960 px และภาพ 360° กว้าง 1024 px (ขนาดใหญ่สุดที่ต้นทางให้ฟรี) ส่วนภาพอื่นกว้างได้ถึง 1600 px
