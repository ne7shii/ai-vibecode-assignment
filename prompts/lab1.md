# LAB 1 · ฟังโรงแรม → User Story

📋 เปิด Claude Code เซสชันใหม่ที่โฟลเดอร์ `sabaijang/` แล้ววางกล่องนี้

```text
อ่าน interview/INTERVIEW.md (บันทึกสัมภาษณ์ทีมงานและผู้เข้าพักของ "CWN สบายจัง รีสอร์ท" ภูเก็ต รอบแรก) แล้วเขียนไฟล์ USER-STORIES.md
1. ต้นไฟล์ใส่ "ข้อมูลตั้งต้น" เป็นตาราง: ประเภทห้อง (รหัส R01, R02, …) · ซีซั่น · โปรโมชั่น (รหัส PR-01, PR-02, …) แยกกลุ่ม "โปรราคา (เลือก 1 อันที่ถูกที่สุด)" / "ซ้อนได้" / "แผนราคา" · ลำดับคิดส่วนลดตามที่ทีมงานเล่า
2. เขียน User Story แบบ "ในฐานะ… ฉันอยาก… เพื่อ…" ให้ครบทุกเรื่องที่ทุกคนพูด ใส่รหัส US-01, US-02, … จัดเป็นหมวด (ค้นหาห้อง · ราคาซีซั่น · โปรโมชั่น · จองและจ่ายเงิน · ยกเลิกและเปลี่ยนแปลง · สมาชิก · ข้อมูลโรงแรมและภาษา · หลังบ้าน · ความเป็นส่วนตัว)
3. แต่ละข้อมี "เกณฑ์ยอมรับ" 1–3 ข้อ ที่ตรวจได้จริง ใช้รหัสห้องและวันที่จริง · เรื่องเงินให้มีตัวอย่างคิดเลขอย่างน้อย 1 ตัวอย่าง เช่น R01 พักคร่อม 30 เม.ย. – 1 พ.ค. ราคาแต่ละคืนเท่าไร รวมเท่าไร
4. ติดป้ายความสำคัญ Must / Should / Could · จุดที่ทีมต้องตั้งสมมติฐานเองให้ติด ⚠️ แล้วโยงไปคำถาม
5. ท้ายไฟล์ใส่ "คำถามที่ต้องถามโรงแรม" (รหัส Q1, Q2, … บอกว่ากระทบ US ไหน) และ "เรื่องที่พูดขัดกันเอง" (ใครพูดว่าอะไร ขัดกับใคร)
ใช้ภาษาไทยง่าย ๆ ใน story ห้ามใช้ศัพท์โปรแกรม (database, API) · ยังไม่ต้องอ่าน interview/OWNER-ANSWERS.md
แล้วสรุปเป็นตาราง: รหัส | เรื่อง | ใครขอ | ความสำคัญ และนับจำนวน Must / Should / Could
```
